Protocol Details

Supported HTTP protocols and their specifications

HTTP/1.1

The classic text-based HTTP protocol. Uses a request-response model over TCP.

RFC RFC 9110, 9112
Transport TCP (plain / TLS)
Multiplexing No (pipelining limited)
Neta Codec HttpServerDuplexe

HTTP/2 (h2)

Binary framing protocol with multiplexing, server push, and header compression (HPACK). Negotiated via TLS ALPN with the "h2" identifier.

RFC RFC 9113
Transport TCP + TLS (ALPN "h2")
Multiplexing Yes (stream-based)
Neta Codec Http2ServerDuplexe

HTTP/3 (h3)

The latest HTTP version running over QUIC (UDP). Features built-in encryption, faster connection setup (0-RTT), and improved head-of-line blocking resistance.

RFC RFC 9114
Transport UDP (QUIC)
Multiplexing Yes (no HOL blocking)
Neta Codec Http3ServerDuplexe
