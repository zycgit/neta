About Neta HTTP Server

Built with the new nHTTP server API on top of the Neta AIO framework

What is Neta?

Neta is a high-performance, asynchronous network application framework built on Java AIO. It provides a bidirectional programming model with its own unique abstractions for protocol stack processing and data flow control.

The framework features a pipeline architecture where data flows through ProtoHandler and ProtoDuplexer components, enabling flexible protocol composition through a declarative API.

Key Features

Architecture Java AIO (NIO2)
Pipeline Model Bidirectional Duplex
Protocols HTTP/1.1, HTTP/2
TLS Support TLS 1.2 / 1.3 + ALPN
Concurrency Non-blocking / Event-driven
Routing ALPN Protocol Negotiation
