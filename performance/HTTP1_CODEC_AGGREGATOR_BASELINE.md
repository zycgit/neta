- 正式 full run 命令：

HTTP/1.x

```bash

  'Http(Aggregator|Codec)Benchmark.(neta|netty)_.*' \
  -wi 3 -i 5 -w 1s -r 2s -f 1 -prof gc -foe true
```

WebSocket

